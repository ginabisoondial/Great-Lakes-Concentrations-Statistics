# Great Lakes Ice Concentration Analysis

**Overview**:
This project analyzes ice concentration data from the Great Lakes for the
2021–2022, 2022–2023, and 2023–2024 periods using C and GNUPlot.
The program reads raw data files, performs statistical calculations, identifies
maximum and minimum ice concentrations, and generates data files used to
create daily and monthly plots.

**Features**:
- Calculate yearly average ice concentration for each lake
- Compare ice concentration between years
- Find the highest and lowest average concentrations
- Identify the highest ice concentration for each lake
- Determine the highest concentration across the entire dataset
- Generate indexed data files for plotting
- Calculate monthly average ice concentrations
- Create daily and monthly GNUPlot visualizations

**Technologies**:
- C
- GNUPlot
- File I/O
- Arrays and 2D arrays
- Functions
- Loops and conditional statements
- Data analysis

**Data**:
The project uses three datasets:
- `2023_2024_Great_Lakes_Data.txt`
- `2022_2023_Great_Lakes_Data.txt`
- `2021_2022_Great_Lakes_Data.txt`

**Analysis**:
The project examines ice concentration trends across Lake Superior,
Michigan, Huron, Erie, Ontario, and St. Clair. One notable observation was
the large variation in St. Clair's ice concentration between years, while
the highest overall concentrations occurred during the first half of 2022.

**Visualization**:
GNUPlot was used to create daily ice concentration plots for each lake,
combined Great Lakes plots, and monthly average comparisons.
